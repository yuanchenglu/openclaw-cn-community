# OpenClaw 网站首页改版设计方案

## 1. 背景与现状分析

### 1.1 当前痛点
目前的 OpenClaw 官网首页承载了过多的营销信息与冗余入口，导致核心用户（开发者/技术人员）在进入的一瞬间无法快速锁定核心价值——即“此时此刻我该怎么把这个东西跑起来”。
- **认知负荷过高**：首页层级复杂，用户需要自行寻路才能找到“开始上手”的教程。
- **转化路径过长**：从“访问首页”到“第一次成功运行”的点击次数过多，每多一次点击就意味着一部分用户的流失。
- **缺乏极客感**：作为一款技术工具，直接展示“能够工作的代码”比任何文案都更有说服力。

### 1.2 用户画像与诉求
我们的核心用户是务实的开发者或技术爱好者。
- **Talk is cheap, show me the code.**
- 他们希望在 **3-5 分钟内** 验证此工具是否满足需求。
- 他们讨厌在复杂的文档层级中迷失。

---

## 2. 核心设计理念：Direct to Value (直达价值)

我们必须转变设计思路：**首页即教程，上手即巅峰**。
用户不应该在首页看到虚头巴脑的宣传语，而应该直接看到代码、看到运行结果、看到如何在该死的 5 分钟内把东西跑起来。

---

## 3. 改版方案细节

### 3.1 首页重构：5分钟快速上手 (The "Zero-to-One" Page)

首页不再是传统的 Landing Page，而是展示《5分钟快速上手》的核心内容。这不仅是一篇文档，更是向用户展示工具实力的直接证明。

**页面核心模块规划：**

1.  **极简首屏 (Above the Fold)**
    *   **标题/Slogan**：一句话讲清楚 OpenClaw 是什么。
    *   **核心动作区**：展示一行安装/启动命令 (One-Liner)。例如：
        ```bash
        curl -sSL https://openclaw.color.vip/install.sh | bash
        ```
    *   **效果预览**：右侧或下方展示工具运行起来后的成功截图或 GIF，给用户即时反馈。

2.  **快速配置向导**
    *   通过 Tab 切换展示最基础的配置示例（如：API Key 设置 + 代理设置）。
    *   只展示最简配置，复杂配置全部收折或提供链接到详细手册。

3.  **运行你的第一个任务**
    *   给出一个 Copy-Paste 就能直接运行的 Hello World 级别用例。

### 3.2 导航栏重构 (Navigation Architecture)

砍掉所有冗余入口，只保留用户最高频的三个路径。导航栏应保持极致的克制与专注：

| 导航项名称 | 定位与功能 | 用户预期 |
| :--- | :--- | :--- |
| **5分钟快速开始** | **默认首页 / Home** | "我想立刻试试这个东西能不能用。" |
| **官方手册中文版** | **参考书 / Reference** | "我想深入研究某个配置参数或高级用法。" |
| **社区讨论** | **求助与交流 / Community** | "我报错了怎么办？有没有人遇到过这个问题？" |

*注：Logo 点击也应跳转回“5分钟快速开始”。*

---

## 4. 预期收益

1.  **降低跳出率**：用户既然是来找工具的，直接给工具怎么用，减少无效点击。
2.  **提升转化率**：缩短从“进站”到“Run起来”的时间窗口，极大提升用户留存（Activation）。
3.  **品牌形象重塑**：树立“极简、高效、开发者友好”的硬核技术品牌形象。
